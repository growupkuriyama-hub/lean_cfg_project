Primitive Dyck Numbers: IJFCS Submission Package
=================================================

Paper
-----
Title: Additive Bases from Primitive Dyck Words:
       Regular Underapproximations, Motzkin Coding, and Digit Lifting
Author: Takayuki Kuriyama

Contents
--------

1. primitive_dyck_tkuriyama_IJFCS_submission.tex
   Main manuscript source prepared with the official World Scientific
   IJFCS LaTeX class.

2. ws-ijfcs.cls
   Official World Scientific document class for the International Journal
   of Foundations of Computer Science.

3. ws-ijfcs.bst
   Official World Scientific BibTeX style supplied with the IJFCS template.
   The present manuscript uses an in-file thebibliography environment, so
   this file is included for completeness but is not required by the current
   compilation command.

4. primitive_dyck_representation.py
   Independently enumerates primitive Dyck numbers and computes the minimal
   representation function r(N) by exact integer dynamic programming. Its
   default run checks the exceptional values stated in the manuscript and
   writes the computed table to primitive_dyck_representation_values.txt.

5. primitive_dyck_representation_values.txt
   Output table generated by primitive_dyck_representation.py. This file is
   provided for inspection and is not needed to compile the manuscript.

6. verify_certificates_for_paper.py
   Reproduces the finite sumset certificates used in the paper, including
   the displayed interval inclusions, the finite exceptional-set identity,
   the small-multiple checks, and the stated lower-bound instances. All
   computations use exact integer arithmetic.

LaTeX compilation
-----------------
A standard pdfLaTeX installation such as TeX Live or MiKTeX is sufficient.
Place the TeX source and ws-ijfcs.cls in the same directory and run:

    pdflatex primitive_dyck_tkuriyama_IJFCS_submission.tex
    pdflatex primitive_dyck_tkuriyama_IJFCS_submission.tex

The second run resolves cross-references. No external bibliography database
is required for the present source.

Computational verification
--------------------------
Python 3 is required. The scripts use only the Python standard library.
Run them from the directory containing the files:

    python primitive_dyck_representation.py
    python verify_certificates_for_paper.py

On systems where the Python 3 executable is named python3, use:

    python3 primitive_dyck_representation.py
    python3 verify_certificates_for_paper.py

The first program may take longer because it computes a large initial segment
of the representation function. The second program verifies the finite
certificates appearing in the manuscript. A successful run should finish
without an assertion failure or exception.

Reproducibility note
--------------------
The infinite assertions in the paper are proved symbolically. The Python
programs are used only to reproduce the explicitly identified finite
certificates and to provide an independent computational cross-check of the
representation function.
