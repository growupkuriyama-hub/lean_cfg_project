# V12 limitations and claim boundary

V12 is a real-trace, offline-mutation experiment.  Normal traces are collected
from a live OpenTelemetry Demo deployment, but anomalous labels are generated by
route-preserving operations on the symbolic projection.  It is not evidence
that the same recall will hold for business failures injected into running
services.

The projection deliberately maps all normal traces with the same cart size to
the same word.  Multiple replicas therefore test extraction stability and raw
system variability; they do not increase the number of unique learning inputs.
The primary effective test size is the number of unique projected words.

The direct count/phase invariant is a domain-informed upper baseline, not a
general specification-mining implementation.  It is included to expose whether
the MCFG machinery adds value beyond the exact invariant apparent in this
projection family.

The k-tails implementation is a compact positive-only baseline, not a claim of
feature parity with mature specification-mining or process-mining tools.

Live temporal fault injection, a second system, and broader projection families
remain separate extensions.  The manuscript should call V12 a
count-controlled real-trace projection experiment, not a live-fault external
validation.
